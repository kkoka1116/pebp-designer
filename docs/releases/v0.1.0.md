> **Research use only. Not for clinical use.** PEBP Studio is not a medical device. It has not been cleared or approved by any regulator or clinically validated, and nothing designed with it has been printed, cast or bench-tested yet. Do not use it to diagnose or treat a patient. Clinical choices stay with the clinician: the software stores and flags them and never makes them.

PEBP Studio turns an infant's maxillary intraoral scan into a design for the pre-epiglottic baton plate (Tübingen palatal plate): the base plate with the published Tübingen extension, three try-in prototypes, QC against the published rules, and printed tooling to cast the final plate in cold-cure PMMA with its safety wire. It runs entirely on your computer and sends nothing anywhere.

This is the first numbered release and the first with ready-to-run downloads.

## Download

| Computer | File |
| --- | --- |
| Mac with Apple silicon (M1 or later) | `PEBP-Studio-0.1.0-macos-apple-silicon.zip` |
| Mac with an Intel processor | `PEBP-Studio-0.1.0-macos-intel.zip` |
| Windows 10 or 11, 64-bit | `PEBP-Studio-0.1.0-windows-x64.zip` |

No Python is needed. The builds are not code-signed yet, so macOS and Windows warn on the first start: [INSTALL.md](https://github.com/kkoka1116/pebp-designer/blob/v0.1.0/docs/INSTALL.md) shows how to open them. `SHA256SUMS.txt` lists each file's checksum.

Each build was checked before upload on synthetic scans only: the frozen command line designed a synthetic palate with the published extension, and the Studio server checks passed against the built app.
